## Notes

- The two G1 findings are copy-only drift, not structural contract violations:
  both plugins add a clause to explain an either/or config path. The validator
  enforces the copy rules but not the spec's exact wording, so these pass CI
  while still differing from the audit table.
- No plugin or theme changes are made by this audit; the report is the only
  change.

## Resolution

The spec owner reviewed the two G1 findings and ruled that the shipped hints
are correct: `sl_departures` `stop_name` and `yr_weather` `location` explain
the either/or config path and are the copy we want to keep.

- Resolution: **spec drift, fixed on the host side.** Calvin's
  `docs/design/2026-10-31-plugin-copy.md` rows 126 (`sl_departures`
  `stop_name`) and 158 (`yr_weather` `location`) will be updated to match the
  shipped copy.
- Plugin change: none. The original table above is kept unchanged as the audit
  record.
- Effective result: **7/7 gates pass** once the host spec update lands. Until
  then the G1 row records the copy as it stood at audit time.
