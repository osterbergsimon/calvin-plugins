# Project
Plugin and theme repository for the Calvin dashboard (host app lives in a separate repo, `osterbergsimon/calvin`). Users install these plugins into Calvin. A plugin that breaks its manifest or leaks a credential breaks installs or exposes a user's accounts.

## Layout
path | what lives there
--- | ---
`<plugin>/plugin.json`, `<plugin>/plugin.py` | One plugin: manifest and SDK-based implementation. Tests sit beside as `test_<id>.py`.
`chromecast/frontend/`, `test-plugin-frontend/frontend/` | Prebuilt `dist.js` web components; their source lives in this repo (owner's answer).
`midnight-theme/theme.json` | The only theme.
`plugins.json` | Repo manifest, generated by `scripts/rebuild-manifest.py`.
`scripts/validate_plugins.py` | Metadata validator (static, does not import plugins).
`scripts/create_plugin.py` | Plugin scaffold, tested by `test_create_plugin.py`.
`conftest.py`, `pytest.ini` | Shared test helper and `asyncio_mode=auto`.
`CREATING_PLUGINS.md` | The plugin authoring guide.
`docs/` | Specs, plans and audits.
`.github/workflows/` | `ci.yml` and `rebuild-manifest.yml`.

## Branches and issues
Default branch and PR base: `main`. CI also lists `develop`, which is being removed (owner's answer). Issues use beads (`bd`), key prefix `CPL-`. Branches are named like `cpl-8-<slug>`.

## Checks
command | when | where it is written
--- | --- | ---
`python scripts/validate_plugins.py <plugin>` | Any plugin change | CREATING_PLUGINS.md
`python3 scripts/validate_plugins.py` | Before PR, all plugins | docs/audits/2026-10-31-rc-gates.md
`cd ../calvin/backend && uv run pytest ../../calvin-plugins/<plugin>` | Plugin change | CREATING_PLUGINS.md, pytest.ini
`python3 scripts/rebuild-manifest.py` | Only when a manifest changed (overwrites `plugins.json`) | README.md

Tests need the Calvin backend venv and a Calvin checkout, found at `../calvin` (owner's answer). CI runs the whole repo against the Calvin tag in `CALVIN_REF` (.github/workflows/ci.yml). If no Calvin checkout is available, say so; do not claim tests passed.

## Private data
`.env` files, `.beads-credential-key`, `.beads/dolt/`, `.dolt/`, `*.db` files, `.ci-calvin/` (a Calvin clone, not this repo's code).

## Acts on the host
`system-monitor/plugin.py` calls `vcgencmd` via subprocess (read-only temperature). `chromecast/plugin.py` talks to cast devices on the local network. Plugins for immich, mealie, lychee, unsplash, imap, sl_departures and yr_weather call real external services or accounts. Workers stub these in tests; never hit real hosts.

## Exposure
Public. Keep out of commits: credentials, API keys, real hostnames or IPs of a user's services, mailbox details, and real account data in test fixtures or docs. Use placeholders.

## Where decisions live
- `docs/superpowers/specs/` and `docs/superpowers/plans/`: design specs. Do not change without an issue saying so.
- `docs/audits/`: audit records, kept as written (see its Resolution section).
- Plugin copy rules live in Calvin's `docs/design/2026-10-31-plugin-copy.md`, outside this repo.
- `CALVIN_REF` in `.github/workflows/ci.yml`: pinned Calvin release; bump only when told.
